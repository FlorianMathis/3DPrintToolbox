Schritt-für-Schritt Anleitung

So erstellen Sie einen optimalen 3D-Scan mit RealityScan im AR Guidance Mode

Vorbereitung (Setup)

Ein guter 3D-Scan beginnt mit der richtigen Umgebung und dem korrekten Setup.

  • Die weisse Platte: Legen Sie eine saubere, matte weisse Platte (z.B. Karton oder Kunststoff) auf einen gut beleuchteten Tisch. Diese hilft der Software, das Objekt vom Hintergrund zu trennen.
  • Das Objekt: Platzieren Sie das Objekt, das Sie scannen möchten, mittig auf der weissen Platte. Achten Sie darauf, dass das Objekt nicht zu stark spiegelt oder transparent ist.
  • Beleuchtung: Sorgen Sie für eine gleichmässige, diffuse Beleuchtung (Vermeiden Sie harte Schatten oder direktes Sonnenlicht).
  • Smartphone vorbereiten: Öffnen Sie die RealityScan App auf Ihrem Smartphone und stellen Sie sicher, dass Ihre Kameralinse sauber ist.

AR Guidance Mode aktivieren

Der Augmented Reality (AR) Guidance Mode hilft Ihnen, alle Perspektiven des Objekts systematisch zu erfassen.

  • Wählen Sie in der RealityScan App den "+-Knopf" um ein neues Projekt anzulegen.
  • Aktivieren Sie in den Aufnahmeeinstellungen den AR Guidance Mode.
  • Die App wird Sie nun bitten, das gewünschte Objekt vollständig aufzunehmen.
  • Bei der Bildaufnahme erscheinen nun AR-Markierungen oder Boxen um Ihr Objekt, die Ihnen anzeigen, aus welchen Winkeln Sie noch Fotos machen müssen.

Der Scan-Vorgang

Jetzt nehmen Sie die Bilder des Objekts auf. Der AR Guidance Mode führt Sie dabei. Machen Sie mindestens 100 Bilder des Objekts und bewegen Sie das Objekt dabei nicht.

  • Systematisches Vorgehen: Bewegen Sie sich in kleinen Schritten im Kreis um das Objekt herum. Nehmen Sie Bilder aus verschiedenen Höhen auf (z.B. Augenhöhe, von schräg oben, von direkt oben).
  • Überlappung: Jedes Foto sollte zu etwa 50-70% mit dem vorherigen Foto überlappen.
  • Grüne Markierungen: Im AR Guidance Mode sehen Sie, dass die AR-Boxen grün werden, wenn ein Bereich ausreichend erfasst wurde. Ihr Ziel ist es, das gesamte Objekt "grün" zu färben.
  • Ruhige Hand: Halten Sie das Smartphone bei jedem Foto möglichst still, um Unschärfen zu vermeiden.

Abschluss & Export

Sobald alle Bereiche des Objekts abgedeckt sind, können Sie den Scan verarbeiten lassen.

  • Prüfen Sie im 3D-Vorschaumodus der App, ob das Modell vollständig und ohne Lücken (Löcher) ist.
  • Klicken Sie auf Weiter (Next). Nach Abschluss der initialen Verarbeitung können Sie das Modell zuschneiden (Cropping), um Teile der Umgebung zu entfernen (z. B. weisse Platte). Dann auf Bereit zur Verarbeitung (Ready to Process).
  • Vergeben Sie ihrem Projekt einen Titel (z. B. "Katze") und lassen Sie alle anderen Einstellungen so wie sie sind. Drücken Sie dann "Projekt verarbeiten (Process project)". Die Bilder werden nun in die Cloud geladen und in ein 3D-Modell umgewandelt.
  • Exportieren Sie das Modell (z.B. als OBJ, FBX oder GLTF), um es weiterzuverarbeiten oder für den 3D-Druck vorzubereiten.

ANLEITUNG FÜR 3D SCAN

Schritt-für-Schritt Workflow mit AR Guidance Mode.

1. Vorbereitung (Setup)

  • Die weisse Platte: Legen Sie eine saubere, matte weisse Platte auf einen gut beleuchteten Tisch.
  • Das Objekt: Platzieren Sie das Objekt mittig auf der weissen Platte. Achten Sie darauf, dass das Objekt nicht zu stark spiegelt oder transparent ist.
  • Beleuchtung: Sorgen Sie für eine gleichmässige, diffuse Beleuchtung (Vermeiden Sie harte Schatten).
  • Smartphone vorbereiten: Öffnen Sie die RealityScan App und reinigen Sie die Kameralinse.

2. AR Guidance Mode aktivieren

  • Wählen Sie in der App "Neues Projekt".
  • Aktivieren Sie den AR Guidance Mode in den Aufnahmeeinstellungen.
  • Erfassen Sie die Oberfläche (weisse Platte), bis das AR-Raster einrastet.
  • AR-Markierungen zeigen an, aus welchen Winkeln Fotos benötigt werden.

3. Der Scan-Vorgang

  • Systematisches Vorgehen: Bewegen Sie sich in kleinen Schritten um das Objekt.
  • Überlappung: Jedes Foto sollte zu etwa 50-70% überlappen.
  • Grüne Markierungen: Färben Sie das gesamte Objekt durch Fotos im AR-Modus grün.
  • Ruhige Hand: Halten Sie das Smartphone bei jedem Foto still.

4. Abschluss & Export

  • Prüfen Sie im 3D-Vorschaumodus, ob das Modell vollständig und ohne Löcher ist.
  • Klicken Sie auf Verarbeiten (Process).
  • Schneiden Sie das Modell nach Abschluss zu (Cropping).
  • Exportieren Sie das Modell (z.B. als OBJ, FBX oder GLTF) für den 3D-Druck.
